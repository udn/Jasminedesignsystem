## Parent Research Insights (Use for Emotional Copy)

These are real concerns and hopes from target parents — use as emotional triggers in copy:

### Key Parent Concerns (Address These)
- **Proximity**: Parents value close-to-home schools so young children don't get tired
- **Speech development**: Some children have speech delay — parents seek schools that help with communication skills
- **Play-based learning**: Parents want children to enjoy school without academic pressure ("belajar itu menyenangkan")
- **Safety & comfort**: "Tempat yang aman, nyaman, dan fun" — top priority for first-time parents
- **Social development**: Building confidence, learning to socialize with peers
- **Slow-to-warm-up children**: Need patient, supportive environment and dedicated educators
- **Financial consideration**: Parents compare with international schools — value quality at accessible pricing
- **Bilingual concerns**: Parents ask about target (exposure vs active), methods, teacher qualifications, parent guidance, progress tracking

### What Parents Hope For
- Anak lancar berkomunikasi dan berinteraksi
- Anak senang sekolah, tahu bahwa belajar itu menyenangkan
- Lingkungan pertemanan yang positif dan aman
- Stimulasi tumbuh kembang sesuai usia (motorik, sensorik, komunikasi, sosial, kemandirian)
- Anak percaya diri dan berani mencoba hal baru
- Progress yang terukur dan terkomunikasikan ke orang tua

## Per-Page Structure & Limits

### 1. Hero Section (every page)

| Element | Label | Limit | Note |
|--------|--------|--------|------|
| Headline | H1 | Maksimal 6 kata | Tulis jumlah karakter |
| Subheadline | H2 | Maksimal 15 kata | Tulis jumlah karakter |
| Primary CTA | CTA | 2–4 kata | Tulis jumlah karakter |
| Supporting microcopy | Body | Maksimal 90 karakter | Tulis jumlah karakter |

### 2. Feature Sections (3 blocks per page)

For each block:

| Element | Label | Limit | Note |
|--------|--------|--------|------|
| Headline | H2 | Maksimal 6 kata | Tulis jumlah karakter |
| Description | Body | Maksimal 180 karakter | Tulis jumlah karakter |
| Benefit bullets | List | 3 bullets, maksimal 80 karakter per bullet | Tulis jumlah karakter per bullet |

**Use real features only**, e.g.:

- Pendidikan Islami & karakter
- Metode Ummi Al-Qur'an
- Fasilitas aman & modern
- Ekstrakurikuler modern (Coding, English, dll)
- Lingkungan aman & terpercaya

### 3. Social Proof Section

- Provide a **testimonial framework template**
- Write **3 realistic parent testimonials** in Bahasa Indonesia
- Add **trust signals** based on real facts (fasilitas, metode, keamanan, lokasi)

### 4. FAQ Section

- **8 questions + answers**
- Address real parent objections:
  - Keamanan anak
  - Metode pembelajaran
  - Usia pendaftaran
  - Trial class
  - Fasilitas
  - Nilai Islami
  - Persiapan SD
  - Cara daftar
- **Each answer**: maksimal 120 kata

### 5. Footer Copy

- Navigation labels
- Short brand statement (maksimal 120 karakter)
- Contact information (use only: 081328846089, 085229552707, lokasi di atas)
- Legal trust message

## Formatting Requirements

- Label all elements clearly: **H1**, **H2**, **Body**, **CTA**
- Include **character counts** beside each element
- Use persuasive emotional triggers: keamanan, masa depan anak, golden age
- Use power words naturally: terpercaya, terbukti, unggulan, aman, terbaik
- Avoid exaggeration or unrealistic claims
- Use clean Markdown formatting
- Structure output so it can be **directly imported into Figma content layers**
